THERMAL SENSE SIH26051 - REPLACEMENT PACKAGE

This package is the complete uploaded project restored from the user's full frontend+backend archive.
The previous generated final package had stale 3D files; this package preserves the latest uploaded source tree.

Windows local run:
1. Open terminal in thermal-sense/backend
2. npm install
3. npm start
4. Open a second terminal in thermal-sense/frontend
5. npm install
6. npm run dev

Backend: http://localhost:5000
Frontend: http://localhost:5173

Do not copy node_modules between machines. Run npm install on the target machine.
NASA POWER remains the climate-data source; no synthetic climate fallback is used by the application.
